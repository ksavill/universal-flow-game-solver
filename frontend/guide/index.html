Start with a clear board

Choose a JPEG or PNG screenshot of an unplayed puzzle. Include the entire grid and every colored dot. On a phone, you can also take a photo of another screen. A screenshot usually gives the cleanest result because it avoids glare and perspective distortion.

  1. Open the solver and select Choose image, take a photo, or paste a screenshot from your clipboard.
  2. If the outline needs adjustment, move its four corners to the board edges. Count the rows and columns before continuing.
  3. Compare the detected dots with the original image. Tap a cell to correct its color or remove an extra dot.
  4. Once each color has exactly two dots, select Solve.

Try the included demo first if you want to see the process before importing your own image.

What makes a valid puzzle?

Each color needs two endpoints. A solution connects each pair using horizontal and vertical steps, without two paths occupying the same cell. When filling is required, every available cell must belong to a path. A hole is an unavailable cell, not a blank square that a path must cover.

The browser edition supports square and rectangular grids from 2 × 2 to 20 × 20, including holes entered manually. It does not yet support bridges, walls, warps, hexagonal boards, circular boards or text recognition. A screenshot of an unsupported variant may look plausible after detection but represent different rules.

Check the dots before solving

An extra dot, a missing endpoint or an incorrect row count can turn a solvable board into an impossible one. Review all pairs, especially similar colors and dots close to bright reflections. The editor highlights colors that do not have exactly two endpoints.

If a photograph is hard to read, take another with the screen facing the camera, reduce reflections and include all four corners. If a screenshot includes drawn paths, clear the puzzle in its original game before capturing it again.

When a solve takes longer

The first solve downloads the solver. After that, the search time depends on the arrangement of endpoints and the amount of empty space, not just the board size. A larger board can sometimes be easier than a smaller one.

A timeout means the search ran out of time; it does not prove there is no solution. Recheck the board and try again with more time if available. Stop ends the current operation and leaves your board available for another attempt. Processing details show the current stage and elapsed time; the search has no reliable percentage-complete estimate.

Save a puzzle for later

Saved puzzles stay in this browser on this device. Use the Library to reopen them, or export a .flow file to keep a separate copy. Import that file on another device to continue there. Clearing site data can erase the local library, so export anything you want to keep.

You can also start with Blank board instead of an image. Set its dimensions, place both dots for each color and mark any holes, then solve.

Privacy and problem reports

The solver processes images locally and does not send your puzzle images to a solving server. Optional problem reports can be previewed, saved locally or downloaded. They are not submitted automatically.

Advertising, when enabled on this guide, is separate from the solver and never unlocks a puzzle or a result. Read our privacy and advertising information for details.
